📚 Demo-login-app-IDB — Architecture & Runbook

Source: /home/amr/Demo-login-app-IDB/catalog-info.yaml

1. Service Overview

The Demo-login-app-IDB microservice manages authentication, session handling, and credential verification for the ShopScale platform.

2. Active Infrastructure & Environment Binding

When Infrastructure Claims (PostgreSQL, Redis, S3) are requested via Backstage Self-Service, Crossplane generates Custom Resource YAMLs in infra/ and injects connection secrets into process environment variables (DB_HOST, REDIS_HOST, S3_BUCKET).

3. Operational Playbook

• Health Check: GET /healthz
• ArgoCD GitOps Sync: Automatic upon git push main
• Emergency Rollback: argocd app sync demo-login-app --revision HEAD~1
